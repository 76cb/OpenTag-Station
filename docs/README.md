# Developer notes

Notes for people working on the firmware. They describe what the code does now.

The user manual is published at <https://76cb.github.io/OpenTag-Station-Docs/>.
Its source is [`../documentation-site/`](../documentation-site/README.md).
Anything a station owner or an API client needs (setup, daily use, troubleshooting, the REST API,
configuration keys, Spoolman and FilaBridge behaviour, the tag format) lives there, not here.

| File | Content |
|---|---|
| [architecture.md](architecture.md) | Layers, source tree, tasks, how a read, weigh, write and assignment flow through the code |
| [runtime-memory.md](runtime-memory.md) | Task stacks and priorities, memory budgets, HTTP and JSON limits, and the CI tools that enforce them |
| [tag-writer.md](tag-writer.md) | Tag write and clear engine, recovery file, weigh and save rules, NFC write allow-list |
| [releasing.md](releasing.md) | Release checklist and the hardware acceptance script |
| [web-flasher.md](web-flasher.md) | How the USB installer page is built, checked and deployed |
| [production-nfc.md](production-nfc.md) | Redirect stub kept for a link from `third_party/`; the content is in [tag-writer.md](tag-writer.md#nfc-write-allow-list) |
| [community-catalog.md](community-catalog.md) | The postponed Community catalog: what is in the tree and how it is switched |
| `images/` | Screenshots used by the top-level README, generated by `tools/refresh_public_images.py` |
