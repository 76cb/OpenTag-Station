# Community postponed to 1.1

Community import/search is disabled for 1.0 after physical ESP32-S3 testing demonstrated a miniz inflater-state memory overwrite. The implementation is retained for redesign in 1.1.

There is no Community source, search, import or update action in production 1.0. Use **My Spools** or **My Filaments** to choose Spoolman inventory and create a physical spool on the station. No browser is required for ordinary spool/tag work.

Existing catalog files from older releases are left untouched by normal OTA and are never accessed. Factory installs omit the catalog. Do not enable Community on a production station.
