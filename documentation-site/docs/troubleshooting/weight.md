# Weight mismatch or unstable readings

Find the cause of a discrepancy before changing canonical usage.

## Before you start

Known reference mass, unloaded platform and the correct scale profile.

## Steps

1. Check ADC ready, raw count changes and stable/fresh samples. Inspect excitation/signal leads if fixed or saturated.
2. Remove mechanical contact and cable tension; verify the platform supports the whole spool with no external filament pull.
3. Tare with the platform empty, then verify calibration using a known reference mass.
4. Compare gross mass minus the actual empty-spool weight to Spoolman remaining mass. Correct an unknown/wrong tare in canonical inventory.
5. Repeat explicit Weigh after corrections and review the new receipt.

## Expected result

Zero, reference mass and repeated spool measurements are consistent within recorded acceptance tolerances.

## If it fails

Do not auto-update from an unexplained discrepancy. Concurrent print consumption can cause an expected-value conflict. Software stability is not proof of mechanical accuracy.
