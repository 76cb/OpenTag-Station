OpenTag Station

Browser Firmware Installer

Use this page for a first installation or to recover a station over USB. After installation, use the station's authenticated local A/B updater for normal firmware updates.

This installer requires desktop Chrome or Edge with Web Serial support. Open this installer from its HTTPS GitHub Pages address.

Requirements

  • Chrome or Edge on a desktop computer
  • USB connection to a WT32-SC01 Plus

First-install and recovery flashing can erase local configuration and scale calibration. Back up settings when possible and review the erase choice in the installer before continuing.

If automatic connection fails, place the ESP32-S3 in download mode as described in the installation guide.
